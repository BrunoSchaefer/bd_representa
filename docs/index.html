Baixar os dados

Todos os bancos estão em .csv.gz (separador ;, UTF-8) na release mais recente. Os dicionários de variáveis estão em 3 Produtos finais/dicionarios.

# R
cand <- data.table::fread("https://github.com/BrunoSchaefer/bd_representa/releases/latest/download/bd_candidatos_camara.csv.gz")

Dados pessoais: CPF e título eleitoral foram trocados por identificadores pseudônimos (*_hash), que continuam a ligar a mesma pessoa entre bancos e anos. E-mails e contatos foram removidos, e a data de nascimento foi reduzida ao ano.

Fontes: TSE (Portal de Dados Abertos), Base dos Dados, IBGE e literatura especializada (classificações ideológicas e organizacionais dos partidos). Elaboração: Bruno Schaefer (IESP-UERJ). Dados sob licença CC BY 4.0.
